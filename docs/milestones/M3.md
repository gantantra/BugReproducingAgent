# M3 — AI Gateway, Flow Artifacts, `intake_to_flow`, `propose_experiments`, Eval Harness

M3 is not "integrate DeepSeek." M3 is "pass the eval harness for `intake_to_flow` and `propose_experiments`."

## Governing principle

Playwright produces evidence. Deterministic software normalizes and measures evidence. DeepSeek interprets and prioritizes evidence. Humans authorize consequential transitions.

## Entry criteria

- M2 exit criteria met; M1 gate still green in CI.
- Explicit `proceed`.
- For live-mode verification only: `DEEPSEEK_API_KEY`, `DEEPSEEK_BASE_URL`, and the three model IDs (open question Q5). Replay-mode work is not blocked by their absence.

## Scope

1. `packages/ai-gateway`: `LlmProvider` interface, DeepSeek adapter (fetch-based, no SDK), request/response mapping, table-driven error classification, retry/backoff/circuit breaker, capability probing with the TTL cache and the degradation matrix, the six-dimension budget enforcer, the cost ledger with pre-dispatch `IN_FLIGHT` rows, and the `RecordedProvider` test double.
2. Validation pipeline: parse -> strict schema -> unknown-field rejection -> reference validation -> one bounded repair -> typed `AI_INVALID_OUTPUT`.
3. `packages/ai-flows`: flow artifact loader with `flowHash` enforcement, the turn loop, tool dispatch with double allowlist enforcement, `FlowResult` partial/inconclusive typing.
4. `packages/tools`: the three `propose_experiments` tools (`get_flow`, `get_application_constraints`, `get_previous_experiment_summary`) plus the shared tool contract and its contract test.
5. Flow artifacts `/ai/flows/intake_to_flow/` and `/ai/flows/propose_experiments/` with `flow.yaml`, `system.md`, `examples.jsonl`, `eval/`.
6. `investigate intake` wired to `intake_to_flow`; `investigate plan` wired to `propose_experiments` and to gate-1 proposal rendering.
7. `/eval/harness`: `runner.ts`, `scorer.ts`, `judge.ts`; datasets for intake and propose; `/eval/reports/baselines.json`.
8. Secret-hygiene tests for the adapter.

## Out of scope

`classify_runs`, `analyze_pass_fail`, `suggest_minimization`, `generate_report` and their tools (M4, M6, M7). Frequency statistics (M5). Streaming. Any write tool.

## Interfaces touched

`LlmProvider` (implemented), `SecretStore` (first real consumer), tool contract (first three tools), `MetadataStore` (AI call ledger, capability cache), flow artifact contract.

## Exit criteria

1. Replay-mode eval passes every M3 gate in `docs/evaluation/eval-gates.md`, including 100% on all shared checks and all negative cases.
2. Import-graph test still proves `execution` and `evidence` cannot reach `ai-gateway`.
3. With the provider stubbed to fail on every call, `investigate run`, `investigate doctor`, and `investigate suite generate` still work; `intake` and `plan` fail with typed `AI_PROVIDER_UNAVAILABLE` and no partial persistence.
4. Every AI call writes a ledger row before dispatch and updates it after; a killed process leaves an `IN_FLIGHT` row.
5. Capability probes run at most once per cache miss per capability, cache in the metadata store, and yield `unknown` (not `unsupported`) on transport failure. The degradation matrix is exercised by tests for all four quadrants.
6. Budget exhaustion in each of the six dimensions produces the correct typed stop reason, and `intake_to_flow`/`propose_experiments` return `inconclusive` (not partial) since neither is partial-capable.
7. One repair attempt only; a second validation failure yields `AI_INVALID_OUTPUT` with both reports and zero persisted domain records.
8. A flow whose directory bytes changed without a version bump is rejected at load.
9. Secret-hygiene tests pass: no key material in ledger rows, logs, artifacts, or error messages.
10. A tool call outside the allowlist is refused, charged, warned, and raises at flow completion.
11. Live mode verified for at least the smoke subset **if** Q5 is answered; otherwise reported explicitly as unverified.
12. All M1 and M2 gates still pass.

## Acceptance tests

| ID | Test |
| --- | --- |
| M3-AT-1 | Error classification table: recorded fixture responses map to the exact expected class, including 400-with-context-length and an auth body that must not be reclassified as retryable |
| M3-AT-2 | Retry policy: `RATE_LIMIT` honours `Retry-After` when larger than computed backoff; `AUTH` never retries |
| M3-AT-3 | Circuit breaker opens after 5 consecutive retryable failures, half-opens, re-opens with doubled duration capped at 10 minutes |
| M3-AT-4 | All retries share the flow wall-clock deadline and never exceed it |
| M3-AT-5 | Reference validation: each of the seven checks has a failing case that blocks persistence |
| M3-AT-6 | Field-match check rejects a correct-shaped citation with a wrong value |
| M3-AT-7 | `intake_to_flow` with an out-of-allowlist origin in the report is rejected, not clamped |
| M3-AT-8 | `intake_to_flow` never invents credentials; ungroundable values appear in `unknowns` |
| M3-AT-9 | `propose_experiments` proposal without a falsifier fails schema |
| M3-AT-10 | A proposal declaring a weaker side-effect class than the deterministic classifier fails schema |
| M3-AT-11 | Tool contract test applied to all three tools: no raw bytes, provenance present, completeness slice present, explicit truncation, determinism, read-only under a read-only filesystem with network stubbed to throw |
| M3-AT-12 | Cost ceiling: a call whose worst-case cost would cross `perInvestigationUsd` is refused pre-dispatch with `COST_EXCEEDED` |
| M3-AT-13 | `UNPRICED_MODEL` path enforces token ceilings and warns rather than inventing a price |
| M3-AT-14 | `inferenceMode` that cannot be expressed emits `INFERENCE_MODE_UNSUPPORTED` and does not switch models |
| M3-AT-15 | Pre-transmission redaction verification blocks a deliberately unredacted `ToolResult` |

## Risks

| Risk | Mitigation |
| --- | --- |
| R15 capability drift | Probes with TTL cache keyed by adapter version; `unknown` on failure; degradation matrix tested |
| R16 cost overrun | Six-dimension budgets, pre-flight worst-case check, ledger before dispatch, investigation ceiling wins |
| R18 prompt drift | `flowHash` over all hashed files, recorded per call, load rejected on mismatch |
| R24 key leakage | Branded `Secret`, primitives-only error context, explicit hygiene tests |
| R27 prompt injection | Tools return fixed-field structured facts only; reference validation bounds the damage |
| Q5 unanswered blocks live verification | Replay gates are the blocking CI gate; live status reported honestly as unverified |
| Eval fixtures become stale after a deliberate prompt change | `record` mode refreshes them, and the refresh is a visible commit |
