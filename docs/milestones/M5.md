# M5 — Frequency Execution and Statistics

## Governing principle

Playwright produces evidence. Deterministic software normalizes and measures evidence. DeepSeek interprets and prioritizes evidence. Humans authorize consequential transitions.

## Entry criteria

- M4 exit criteria met; M1–M4 gates green.
- Explicit `proceed`.

## Scope

No AI. This milestone is entirely deterministic.

1. `investigate frequency run --repeat <n>`: repeated execution of the gate-2-approved target sequence with per-repetition and per-attempt accounting.
2. Statistics module: Wilson score interval, Fisher exact test, bootstrap confidence interval for rate differences, and the sequential stopping rule for `--stop-on-confidence`.
3. `FrequencyStatistics` records: requested n, achieved n, valid observations, repetitions with no valid observation, matches of the approved signature, rate, interval, and the counting rule applied.
4. Group comparison statistics: rate difference between two experiment groups with an interval and the interval-overlap verdict.
5. Level-ladder integration: `probable_trigger` promotion now satisfiable; `high_confidence_trigger` requires a matched control set (produced in M6).
6. `minRunsForRate` enforcement (default 10) as a hard promotion requirement.
7. Statistics surfaced through the existing `statistic` reference kind so findings can cite `/rate` and `/interval` fields exactly.

## Out of scope

Minimization and controls (M6). Report rendering (M7). Any AI flow change beyond findings now being able to cite statistics.

## Interfaces touched

`WorkQueue` (repetition-oriented enqueue), `MetadataStore` (statistics table), tool contract (`get_previous_experiment_summary` now returns rates and intervals), reference validation (`statistic` kind with field matching).

## Exit criteria

1. Wilson and Fisher implementations match published reference values to 1e-9, asserted against a table of known inputs.
2. The estimated rate for the seeded intermittent fixture covers its known true rate: the 95% interval covers truth in at least 19 of 20 seeded trials.
3. Reported achieved n equals actual valid observations, exactly.
4. Repetitions with no valid observation are counted and reported separately and are never treated as passes.
5. A product failure is never hidden by an infrastructure retry: the counting rule takes the last non-interrupted attempt per repetition, and `no_retry_hides_product_failure` is extended to assert this through the statistics module.
6. `--stop-on-confidence` stops early and the report states achieved n rather than requested n.
7. Interval-overlap verdicts are computed deterministically and are what `probable_trigger` promotion consults.
8. A finding claiming `probable_trigger` with n below `minRunsForRate` is demoted.
9. Batch stop conditions (`--stop-after-failures`, investigation limits, unreachability circuit breaker) record why the batch ended.
10. All prior gates still pass.

## Acceptance tests

| ID | Test |
| --- | --- |
| M5-AT-1 | Wilson interval table test, including n=0, n=1, p=0, p=1 edge cases |
| M5-AT-2 | Fisher exact test table test |
| M5-AT-3 | Bootstrap CI determinism under a fixed seed |
| M5-AT-4 | Coverage test: 20 seeded trials against the intermittent fixture, interval covers truth in >= 19 |
| M5-AT-5 | Injected infrastructure faults across repetitions: statistics report the correct failure count and the correct no-valid-observation count |
| M5-AT-6 | Requested vs achieved n divergence reported honestly after an early stop |
| M5-AT-7 | `probable_trigger` demoted when n < `minRunsForRate` |
| M5-AT-8 | Overlapping intervals block a `probable_trigger` promotion; disjoint intervals permit it |
| M5-AT-9 | Statistic citation with a wrong `/rate` value -> `AI_REFERENCE_MISMATCH` |
| M5-AT-10 | Unreachability circuit breaker stops the batch with a typed error rather than continuing |

## Eval gates

None (no AI flow introduced). The M5 acceptance gates in `docs/evaluation/eval-gates.md` apply, since statistics feed the level ladder.

## Demo command

```bash
investigate frequency run --workspace ./demo-ws --repeat 100
investigate show --workspace ./demo-ws statistics
investigate classify --workspace ./demo-ws --refresh   # findings can now reach probable_trigger
investigate show --workspace ./demo-ws findings
```

Expected: a rate with a Wilson interval, achieved n, no-valid-observation count, and at least one finding promoted to `probable_trigger` with a statistic citation.

## Risks

| Risk | Mitigation |
| --- | --- |
| R7 defect too rare for the budget | Achieved n and the interval are reported; `INCONCLUSIVE` is a valid outcome; the report states the incidence bound reached |
| R4 retry hiding a failure | Counting rule frozen; gate test extended through the statistics module |
| Statistical mis-specification | Reference-value table tests; Wilson chosen over normal approximation explicitly for small n |
| Long wall clock for 100+ runs | Batch stop conditions; `--stop-on-confidence`; disk-growth guard from M1 |
| Misreading interval overlap as proof | Overlap verdict gates promotion only to `probable_trigger`, never to a root-cause claim |
