# M7 — Reproducer Package and `generate_report`

## Governing principle

Playwright produces evidence. Deterministic software normalizes and measures evidence. DeepSeek interprets and prioritizes evidence. Humans authorize consequential transitions.

## Entry criteria

- M6 exit criteria met; M1–M6 gates green.
- Explicit `proceed`.

## Scope

1. `ReproducerPackage`: a self-contained directory containing a standalone Playwright spec, the resolved emulation parameters, the target definition, the seed, the approved signature predicate as an executable assertion, the control variant, a README, and a manifest of included artifacts with hashes.
2. Static test emission: deterministic codegen from the approved sequence. Runnable under the Playwright runner with no dependency on the agent.
3. Tools: `get_investigation_summary`, `get_approved_findings`, `get_validation_results`, `get_artifact_references`.
4. Flow artifact `/ai/flows/generate_report/`, not partial-capable.
5. Deterministic report renderer with required sections, refusal on invalid references, and the overclaiming lint.
6. `investigate report` and `investigate export`, including export-time redaction verification and integrity re-verification.
7. Eval datasets and gates for `generate_report`.

## Required report sections

| Section | Content | Enforcement |
| --- | --- | --- |
| Summary | What fails, where, at what measured incidence | Required |
| Environment | Target, classification, resolved emulation values, browser and Playwright versions, and the verbatim emulation boundary statement | Required, verbatim string checked |
| Reproduction | The approved minimized sequence, seed, measured rate with interval, achieved n | Required |
| Passing control | The control sequence and its measured rate with interval | Required when one exists; explicit absence statement otherwise |
| Findings | Each approved finding at its validated level with citations | Required |
| Explicit non-claims | What was not established, including the absence of a confirmed root cause | Required |
| Evidence completeness | Every non-`complete` category across cited runs with reasons and counts | Required, consistent with aggregate `CaptureStatus` |
| Limitations | Threshold misses, excluded runs, retention-expired artifacts, unverified checks | Required |
| Artifacts | `ArtifactRef` table: ID, kind, size, SHA-256 | Required |
| Lineage | The chain from intake report to report, with `actor.kind` per hop | Required |

## Out of scope

Jira API writes (post-MVP, needs a write-tool ADR). Hardening, retention expansion, and adversarial eval expansion (M8). Any new finding level.

## Interfaces touched

Tool contract (four new tools), `ArtifactStore` (reproducer package, report artifact), `MetadataStore` (report record), lineage (`emitted_test`, `reported_in`), CLI (`report`, `export`).

## Exit criteria

1. Replay-mode eval passes every M7 gate, with all seven hard rows at 100%/zero.
2. The report renderer refuses to render if any cited finding fails reference validation, exiting 4.
3. Every claim in the rendered report maps to an approved finding ID. An introduced claim, a raised level, or a citation absent from the source finding is rejected.
4. The completeness section is generated from the aggregate `CaptureStatus` and is asserted consistent with it; a mismatch is a render failure.
5. The emulation boundary statement appears verbatim.
6. The overclaiming lint finds zero forbidden phrases, including unqualified "on Android", "on a real device", "on mobile Chrome".
7. The reproducer package runs standalone under the Playwright runner, reproduces at a rate consistent with the recorded interval, and its README states the emulation boundary.
8. `investigate export` re-runs redaction verification over every included artifact and blocks the export on any residue; re-verifies every hash; and includes the completeness summary.
9. A retention-expired cited artifact renders as a tombstone with an honest note, not as an omitted citation.
10. All prior gates still pass.

## Acceptance tests

| ID | Test |
| --- | --- |
| M7-AT-1 | Report with a fabricated citation -> render refused, exit 4 |
| M7-AT-2 | Report claim at a higher level than its source finding -> rejected |
| M7-AT-3 | Report introducing a claim with no approved finding -> rejected |
| M7-AT-4 | Missing completeness section or one inconsistent with aggregate `CaptureStatus` -> render failure |
| M7-AT-5 | Missing or altered emulation boundary statement -> render failure |
| M7-AT-6 | Overclaiming phrase present -> lint failure |
| M7-AT-7 | Reproducer package runs standalone and reproduces the signature |
| M7-AT-8 | Reproducer control runs standalone and passes |
| M7-AT-9 | Export with a deliberately unredacted artifact -> export blocked |
| M7-AT-10 | Export with a corrupted artifact -> exit 9 |
| M7-AT-11 | Retention-expired citation renders as a tombstone |
| M7-AT-12 | Report is byte-identical across two renders of the same validated inputs |
| M7-AT-13 | Tool contract test applied to the four new tools |
| M7-AT-14 | `report` without gate 3 -> exit 2 |
| M7-AT-15 | An investigation with no confirmed root cause produces the explicit non-claim section stating that |

## Eval gates

All M7 gates in `docs/evaluation/eval-gates.md`. Dataset: 8 positive, 6 negative including the hypothesis-not-confirmed case, the `unsupported`-category disclosure case, and the retention-expired citation case.

## Demo command

```bash
investigate report --workspace ./demo-ws --out ./demo-ws/reports/INV-001.md
investigate export --workspace ./demo-ws --out ./demo-ws/exports/INV-001.zip
investigate export --workspace ./demo-ws --verify-only
cd ./demo-ws/investigations/INV-001/reproducer && npx playwright test
```

Expected: a report with all eleven sections, every claim cited, the completeness and non-claim sections present, a clean export verification, and a standalone reproducer that reproduces the failure and whose control passes.

## Risks

| Risk | Mitigation |
| --- | --- |
| R5 emulation overclaim | Verbatim boundary statement, lint on device phrasing, resolved values in the report |
| R9 completeness quietly degraded | Completeness section required and asserted consistent with aggregate status |
| Report becomes narrative rather than evidence | Renderer is mechanical; claims must map to approved findings; levels cannot be raised |
| Reproducer drifts from the agent's execution | Emulation materialised as concrete values; seed recorded; standalone run asserted in CI |
| Export leaks residue | Pre-export verification pass; a hit is an error, not a silent fix |
